Undergraduate Competition

For university students across Rwanda. Two tracks: Infographics and Hackathon.

Tracks

📊

Infographics

Submit one static file and one dynamic visual based on official NISR statistics. Entries are evaluated for clarity, accuracy, and visual impact.

💻

Hackathon

Build a data-driven solution in one of three focus areas. Teams submit a working prototype, source repository, and documentation.

Focus Areas (Hackathon)

  • 🌾 Agricultural Productivity
  • 💰 Financial Inclusion
  • 🚀 Open Innovation

Eligibility

  • Teams of exactly 2 members.
  • At least one Rwandan citizen per team.
  • Previous 1st–3rd place winners are not eligible.
  • Members must be currently enrolled university students.

  • Hackathon: GitHub repository link + deployed application link + documentation file.
  • All submissions must be original work. AI use must be disclosed.
